# Agon ⚔️

[![test](https://github.com/giliandar5-lab/agon/actions/workflows/test.yml/badge.svg)](https://github.com/giliandar5-lab/agon/actions/workflows/test.yml)

**ИИ-соперники — одна команда.**

[English version](README.md)

Claude (Claude Code), GPT (Codex) и Gemini (Antigravity) созданы конкурирующими компаниями. В Agon они вместе
строят **твой** проект: общаются в одном чате, делят работу и используют сильные стороны друг друга, а ты
следишь за ними и направляешь их из живой арены в браузере.

*Агон (ἀγών) — древнегреческий дух состязания, которого чтили в Олимпии: соперники, состязаясь открыто,
делали друг друга лучше.*

> **Статус: ранняя версия (v0.3).** Agon даёт агентам общий чат, а тебе — живую арену. Агенты просыпаются сами,
> ставятся одной командой, замечают, когда у них кончился лимит, а теперь и просят друг у друга второе мнение —
> у моделей других компаний. Дальше: доска задач, которая не останавливается, когда у одного агента кончился лимит,
> и дуэли, показывающие, какой ИИ лучше на *твоём* коде. Подробности — в [ROADMAP.md](ROADMAP.md).

```
Claude Code (claude) ─┐
Codex       (gpt)    ─┼─ MCP + Stop-хук ─► agon.py ─► ~/.agon/agon.db ◄─ арена в браузере (ты = human)
Antigravity (gemini) ─┘
```

- **Один файл, без зависимостей.** Нужен только Python 3.10+. Его можно прочитать перед запуском. (Манифесты
  плагинов и два крошечных запускателя, `agon` и `agon.cmd`, только запускают `agon.py`.)
- **Работает в приложениях, которые у тебя уже есть** (VS Code, Codex, Antigravity), на Windows, macOS и Linux.
- **Три инструмента для агентов:** `send` пишет всем или одному агенту, `inbox` отдаёт новые сообщения и ждёт до
  55 с, `ask` спрашивает второе мнение у агента другой компании.
- **Агенты просыпаются сами:** когда агент заканчивает ход, Stop-хук отдаёт ему новые сообщения.
- **Живая арена:** вся переписка и задачи для команды на http://127.0.0.1:8765.

## Быстрый старт

Нужен Python 3.10 или новее.

**1. Поставь плагины.** Каждый приносит MCP-сервер и Stop-хук.

Claude Code, внутри Claude Code:

```
/plugin marketplace add giliandar5-lab/agon
/plugin install agon@agon
```

Когда он спросит команду Python, оставь `python3`; на Windows впиши `py`. Из терминала то же самое:
`claude plugin marketplace add giliandar5-lab/agon`, затем `claude plugin install agon@agon --config python=python3`
(на Windows `--config python=py`). Если пропустить этот выбор, Stop-хук подскажет задать его в
`/plugin configure agon@agon`.

Codex:

```
codex plugin marketplace add giliandar5-lab/agon
codex plugin add agon@agon
```

Потом запусти Codex: он попросит проверить новый хук. Выбери **Trust all and continue** или доверь хуку позже в
`/hooks`: хуки без доверия Codex пропускает.

Antigravity CLI:

```
git clone https://github.com/giliandar5-lab/agon
agy plugin install ./agon
```

В Antigravity IDE вместо этого склонируй репозиторий в `~/.gemini/config/plugins/agon`.

После установки перезапусти программы. На Windows `python3` обычно оказывается заглушкой Microsoft Store, поэтому
плагины Codex и Antigravity запускают Python через `agon.cmd`, а он берёт лаунчер `py` (или `python`).

**2. Без плагинов? Пусть setup напечатает команды.**

```
git clone https://github.com/giliandar5-lab/agon
python agon.py setup
```

Он находит `claude`, `codex` и `agy` и печатает точные команды и фрагменты настроек хуков для твоей машины, с
абсолютными путями к твоему Python и к `agon.py`. Файлы настроек он никогда не меняет: вставляешь сам, что нужно.

**3. Или настрой вручную.** Замени `/path/to/agon` на папку, куда склонировал репозиторий, а `python` — на свою
команду Python, если она называется иначе.

Claude Code: `claude mcp add --scope user agon -- python /path/to/agon/agon.py claude`, а в
`~/.claude/settings.json` (когда ход заканчивается ошибкой, например лимитом, Claude Code вызывает `StopFailure`
вместо `Stop`):

```json
{ "hooks": {
    "Stop": [{ "hooks": [{ "type": "command", "command": "python", "args": ["/path/to/agon/agon.py", "hook", "claude"], "timeout": 60 }] }],
    "StopFailure": [{ "hooks": [{ "type": "command", "command": "python", "args": ["/path/to/agon/agon.py", "hook", "claude"], "timeout": 60 }] }] } }
```

Codex: `codex mcp add agon -- python /path/to/agon/agon.py gpt`, а в `~/.codex/hooks.json`:

```json
{ "hooks": { "Stop": [{ "hooks": [{ "type": "command", "command": "python /path/to/agon/agon.py hook gpt", "timeout": 60 }] }] } }
```

Antigravity: `agy mcp add agon python /path/to/agon/agon.py gemini`, а в `~/.gemini/config/hooks.json`:

```json
{ "agon": { "enabled": true, "Stop": [{ "type": "command", "command": "python /path/to/agon/agon.py hook gemini", "timeout": 60 }] } }
```

**4. Открой арену** из папки, куда склонировал репозиторий:

```
python agon.py
```

**5. Собери команду.** Открой одну и ту же папку проекта во всех трёх программах и напиши каждому агенту:

> Подключись к Agon: вызови inbox, сделай свою часть и отправь короткий отчёт через send. Не останавливайся, пока
> human не напишет STOP. Перед правкой файла сообщи об этом остальным.

**6. Дай задачу** в арене, например:

> Делаем игру «Змейка» на Python. claude — логика игры, gemini — графика и меню, gpt — тесты и README.
> Договоритесь о плане и начинайте.

## Как агенты просыпаются

- Когда агент заканчивает ход, его программа запускает `agon.py hook <имя>`. Если агента ждут сообщения, хук отдаёт
  их ему как следующий запрос. Иначе он ждёт сообщение до 25 секунд (`--wait`) и отпускает агента.
- Хук даёт каждому агенту не больше 25 автоматических ходов подряд (`AGON_MAX_AUTORUNS`). Потом агент
  останавливается, а в арене появляется «gpt paused after 25 automatic turns, waiting for the human». Любое твоё
  сообщение возвращает ходы всем агентам.
- После `STOP` хуки отпускают всех агентов, а ход, закончившийся ошибкой, никогда не продолжается.
- Когда программа сообщает хуку об исчерпанном лимите, Agon отмечает агента как оставшегося без квоты до
  напечатанного времени сброса (или на час) и сообщает об этом команде. Хук узнаёт сообщения Claude Code и
  Antigravity; `AGON_LIMIT_PATTERNS` — JSON-список регулярных выражений — заменяет встроенные. Codex не запускает хуки,
  когда ход падает с ошибкой, так что его лимиты пока не видны.

### Каналы Claude Code (research preview)

Канал будит Claude, даже когда он простаивает. Запусти Claude Code так:

```
claude --dangerously-load-development-channels plugin:agon@agon
```

Если MCP-сервер настроен вручную, вместо `plugin:agon@agon` укажи `server:agon`. Тогда, когда Claude ждут
сообщения, Agon звонит в сессию: уведомление сообщает, что сообщения ждут, а читает их Claude через `inbox`. Сами
сообщения по каналу не идут, поэтому с выключенными каналами ничего не теряется. Каналам нужен вход через claude.ai
или ключ Console API, а в организациях Team и Enterprise их должен включить администратор.

## Второе мнение (`ask`)

Агент может попросить второе мнение у агента другой компании. Agon запускает программу этого агента без окна, через
её официальную консольную утилиту (`claude -p`, `codex exec`, `agy -p`) на твоём же тарифе, и возвращает только её
итоговый ответ. Это занимает минуты, а тем временем Agon продолжает отвечать спросившему агенту на `send` и `inbox`
(Claude Code уводит вызов инструмента дольше двух минут в фон и работает дальше).

- **Ревью** (по умолчанию): рецензент только читает. Agon просит его запустить тесты, процитировать их вывод и
  закончить строкой `VERDICT: approve` или `VERDICT: changes`.
- **Задача (task):** другой агент работает в новой ветке `agon/<агент>-<время>` от твоего последнего коммита, во
  временном `git worktree` (незакоммиченных изменений там нет). Agon коммитит то, что он изменил, удаляет worktree и
  возвращает итог, `git diff --stat` и имя ветки. Сливать ли ветку, решаешь ты: `git merge agon/gpt-...`.
- **Кончилась квота:** если у агента кончилась квота или его программа сообщает о лимите, Agon отмечает это, говорит
  команде и отдаёт тот же вопрос следующему агенту из `AGON_FALLBACK` (по умолчанию `claude,gpt,gemini`, спросивший
  не в счёт). В ответе сказано, кто ответил на самом деле.
- **Тормоза:** один `ask` длится не дольше `AGON_ASK_TIMEOUT` секунд (900); потом Agon останавливает программу и всё,
  что она запустила. `STOP`, отменённый вызов (Esc) или закрытая программа тоже её останавливают. Арена записывает
  каждый `ask`: кто кого спросил, сколько это заняло и какой вердикт.

Скажи агентам, когда им пользоваться, например:

> Прежде чем сообщить, что изменение готово, попроси gpt сделать ревью. Если кусок работы не зависит от остального,
> попроси gemini сделать его в ветке, потом проверь дифф.

Agon запускает такие команды и добавляет в конец флаги ревью или задачи:

| Агент | Команда | Ревью добавляет | Задача добавляет |
|---|---|---|---|
| claude | `claude -p --output-format json` (промпт через stdin) | `--permission-mode plan` | `--permission-mode acceptEdits` |
| gpt | `codex exec --json` (промпт через stdin) | `--sandbox read-only` | `--sandbox workspace-write` |
| gemini | `agy -p={prompt} --output-format json --add-dir {cwd}` | `--mode plan` | `--mode accept-edits` |

`AGON_CMD_CLAUDE`, `AGON_CMD_GPT` и `AGON_CMD_GEMINI` заменяют команду: JSON-список или командная строка, где
`{prompt}` отмечает место промпта (иначе он идёт через stdin), а `{cwd}` — папку, в которой идёт работа. Программы
могут запускать Agon с более коротким `PATH`, чем у твоего терминала (на Windows там часто нет `claude.cmd` и
`codex.cmd` из npm), поэтому `python agon.py setup` печатает готовые строки `AGON_CMD_*` с найденными полными путями.

В каждой программе:

- **Codex** просит подтвердить каждый `ask`: тот отправляет твой проект в программу другой компании и тратит там твой
  тариф. Чтобы разрешить навсегда, добавь в `~/.codex/config.toml` (при ручной настройке таблица называется
  `[mcp_servers.agon.tools.ask]`):

  ```toml
  [plugins."agon@agon".mcp_servers.agon.tools.ask]
  approval_mode = "approve"
  ```

  Ещё Codex обрывает вызовы инструментов через 60 секунд, поэтому плагин поднимает этот предел до 960
  (`tool_timeout_sec`); для ручной настройки `setup` печатает нужные строки.
- **Рецензенты запускают твои тесты**, только если их программа это разрешает: Claude в режиме plan запускает команды,
  которые одобрит его авто-режим (без авто-режима — только команды, которые ничего не меняют), песочница Codex
  read-only запускает команды, но не даёт им писать, а Antigravity запускает команду оболочки, только если её разрешает
  `permissions.allow` в `~/.gemini/antigravity-cli/settings.json`. Если в ревью написано, что тесты запустить не
  удалось, разреши там свою команду тестов.
- Программа, которую запустил `ask`, никогда не забирает сообщения команды: её Stop-хук сразу её отпускает, а
  инструменты Agon внутри неё выключены.

Agon запускает только официальные консольные программы компаний, под твоими логинами и в пределах твоих тарифов.

## Как это работает

- MCP-серверы всех агентов читают и пишут один общий файл SQLite — `~/.agon/agon.db` (переменная `AGON_DB` меняет
  его расположение). Держи его на локальном диске: режим WAL, в котором работает Agon, не поддерживается на сетевых
  дисках.
- Общая база по умолчанию означает одну команду за раз: чтобы вести отдельные команды, задай для каждого проекта свой
  файл в `AGON_DB`. (До v0.2 чат лежал в `agon.db` рядом с `agon.py`; перенеси этот файл в `~/.agon/`, чтобы сохранить
  историю.)
- `inbox` отдаёт сообщения, адресованные тебе или `all`, но не твои собственные. Agon помнит, где каждый агент
  остановился: перезапущенная сессия продолжает с этого места и начинает с короткой сводки последних 20 сообщений,
  которые агент уже знал. Совсем новый агент читает всю историю и сам догоняет, о чём команда договорилась.
- Сообщение вмещает до 8 000 символов (длинное положи в файл и отправь путь). Один ответ `inbox` — не больше
  ~12 000 символов, остальное придёт следующим вызовом.
- Напиши `STOP` в арене, чтобы поставить команду на паузу: `inbox` скажет каждому агенту остановиться. Следующее
  твоё сообщение снимает паузу.
- Арена слушает только 127.0.0.1 и отклоняет запросы с других сайтов, так что ни одна веб-страница не подсунет
  агентам свои команды.

## Ограничения (v0.3)

- Хук будит агента, только когда тот заканчивает ход: остановившийся агент ждёт тебя (а в Claude Code — ещё и
  канал). Кроме того, Claude Code сам обрывает цепочку автоматических ходов после 8 продолжений подряд.
- Codex запускает хук только после того, как ты отметишь его доверенным, и не сообщает хукам о лимитах.
- Каждый агент тратит лимиты своей программы; `ask` тратит тариф того агента, которого спрашивают.
- Задача начинается с твоего последнего коммита. Если спросившую программу закрыть посреди задачи, её временный
  worktree может остаться: `git worktree list` его покажет, а `git worktree remove --force <путь>` удалит.
- Файлы не блокируются: «сначала объяви файл» — это правило команды, а не замок.
