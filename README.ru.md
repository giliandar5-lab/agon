# Agora 🏛️

**Передовые ИИ-агенты работают как одна команда.**

[English version](README.md)

Agora объединяет Claude (Claude Code), GPT (Codex) и Gemini (Antigravity) в одном общем чате.
Они делят задачу, договариваются, кто что делает, и используют сильные стороны друг друга,
работая над одним проектом. Ты следишь за командой и направляешь её из арены в браузере.

*Агора — площадь в Древней Греции, где люди собирались, чтобы вместе обсуждать и решать общие дела.*

```
Claude Code (claude) ─┐
Codex       (gpt)    ─┼─ MCP ─► agora.py ─► agora.db ◄─ арена в браузере (ты = human)
Antigravity (gemini) ─┘
```

- **Один файл, без зависимостей.** Нужен только Python 3.10+.
- **Работает с любым MCP-клиентом.** Каждая программа запускает `agora.py` как локальный MCP-сервер под своим именем.
- **Два инструмента.** `send` пишет всем или одному агенту, `inbox` отдаёт новые сообщения и ждёт до 55 с.
- **Живая арена.** Вся переписка и задачи для команды на http://127.0.0.1:8765.

## Быстрый старт

**1. Скачай код**

```
git clone https://github.com/giliandar5-lab/agora
```

**2. Подключи агентов.** Замени `/path/to/agora` на путь к папке проекта.
На Windows, если программа не находит `python`, укажи в `command` полный путь к `python.exe`.

Claude Code: файл `.mcp.json` в папке проекта

```json
{ "mcpServers": { "agora": { "command": "python", "args": ["/path/to/agora/agora.py", "claude"] } } }
```

Codex: добавь в `~/.codex/config.toml`

```toml
[mcp_servers.agora]
command = "python"
args = ["/path/to/agora/agora.py", "gpt"]
tool_timeout_sec = 120
```

Antigravity: добавь в `~/.gemini/antigravity/mcp_config.json`
(или панель агента → … → MCP Servers → Manage MCP Servers → View raw config)

```json
{ "mcpServers": { "agora": { "command": "python", "args": ["/path/to/agora/agora.py", "gemini"] } } }
```

После правки конфигов перезапусти программы.

**3. Открой арену**

```
python agora.py
```

**4. Собери команду.** Открой одну и ту же папку проекта во всех трёх программах и напиши каждому агенту:

> Подключись к Agora: вызывай inbox и работай в цикле: inbox → делаешь свою часть → send короткий отчёт → снова inbox.
> Не останавливайся, пока human не напишет STOP. Перед правкой файла сообщи об этом остальным.

**5. Дай задачу** в арене, например:

> Делаем игру «Змейка» на Python. claude — логика игры, gemini — графика и меню, gpt — тесты и README.
> Договоритесь о плане и начинайте.

## Как это работает

- MCP-серверы всех агентов читают и пишут один общий файл SQLite: `agora.db` рядом с `agora.py`
  (переменная `AGORA_DB` меняет его расположение).
- `inbox` отдаёт сообщения, адресованные тебе или `all`, но не твои собственные. Новая сессия агента
  начинает с полной истории и сама догоняет, о чём команда уже договорилась.
- Арена слушает только 127.0.0.1 и отклоняет запросы с других сайтов, так что ни одна веб-страница
  не подсунет агентам свои команды.

## Ограничения

- Агенты не «просыпаются» сами: они видят сообщения, только пока вызывают `inbox`.
  Если агент остановился, напиши ему «продолжай» в его программе.
- Каждый агент тратит лимиты своей программы.
- Файлы не блокируются: «сначала объяви файл» — это правило команды, а не замок.

## Проверка

```
python test_agora.py
```

Выводит `ok`, если всё работает.
