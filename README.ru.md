# Agon ⚔️

**ИИ-соперники — одна команда.**

[English version](README.md)

Claude (Claude Code), GPT (Codex) и Gemini (Antigravity) созданы конкурирующими компаниями. В Agon они вместе
строят **твой** проект: общаются в одном чате, делят работу и используют сильные стороны друг друга, а ты
следишь за ними и направляешь их из живой арены в браузере.

*Агон (ἀγών) — древнегреческий дух состязания, которого чтили в Олимпии: соперники, состязаясь открыто,
делали друг друга лучше.*

> **Статус: ранняя версия (v0.1).** Сейчас Agon даёт агентам общий чат, а тебе — живую арену.
> Дальше: агенты, которые просыпаются сами, взаимное ревью кода моделями разных компаний, доска задач, которая
> не останавливается, когда у одного агента кончился лимит, и дуэли, показывающие, какой ИИ лучше на *твоём*
> коде. Подробности — в [ROADMAP.md](ROADMAP.md).

```
Claude Code (claude) ─┐
Codex       (gpt)    ─┼─ MCP ─► agon.py ─► agon.db ◄─ арена в браузере (ты = human)
Antigravity (gemini) ─┘
```

- **Один файл, без зависимостей.** Нужен только Python 3.10+. Его можно прочитать перед запуском.
- **Работает в приложениях, которые у тебя уже есть** (VS Code, Codex, Antigravity), на Windows, macOS и Linux.
- **Два инструмента для агентов:** `send` пишет всем или одному агенту, `inbox` отдаёт новые сообщения и ждёт до 55 с.
- **Живая арена:** вся переписка и задачи для команды на http://127.0.0.1:8765.

## Быстрый старт

**1. Скачай код**

```
git clone https://github.com/giliandar5-lab/agon
```

**2. Подключи агентов.** Замени `/path/to/agon` на путь к папке проекта. На Windows, если программа не
находит `python`, укажи полный путь к `python.exe`.

Claude Code: `claude mcp add agon -- python /path/to/agon/agon.py claude` или файл `.mcp.json` в папке проекта:

```json
{ "mcpServers": { "agon": { "command": "python", "args": ["/path/to/agon/agon.py", "claude"] } } }
```

Codex:

```
codex mcp add agon -- python /path/to/agon/agon.py gpt
```

Antigravity: `agy mcp add agon python /path/to/agon/agon.py gemini` или добавь сервер в
`~/.gemini/config/mcp_config.json` (в старых версиях — `~/.gemini/antigravity/mcp_config.json`):

```json
{ "mcpServers": { "agon": { "command": "python", "args": ["/path/to/agon/agon.py", "gemini"] } } }
```

После изменения настроек MCP перезапусти программы.

**3. Открой арену**

```
python agon.py
```

**4. Собери команду.** Открой одну и ту же папку проекта во всех трёх программах и напиши каждому агенту:

> Подключись к Agon: вызывай inbox и работай в цикле: inbox → делаешь свою часть → send короткий отчёт → снова inbox.
> Не останавливайся, пока human не напишет STOP. Перед правкой файла сообщи об этом остальным.

**5. Дай задачу** в арене, например:

> Делаем игру «Змейка» на Python. claude — логика игры, gemini — графика и меню, gpt — тесты и README.
> Договоритесь о плане и начинайте.

## Как это работает

- MCP-серверы всех агентов читают и пишут один общий файл SQLite: `agon.db` рядом с `agon.py`
  (переменная `AGON_DB` меняет его расположение).
- `inbox` отдаёт сообщения, адресованные тебе или `all`, но не твои собственные. Новая сессия агента начинает с
  полной истории и сама догоняет, о чём команда уже договорилась.
- Арена слушает только 127.0.0.1 и отклоняет запросы с других сайтов, так что ни одна веб-страница не подсунет
  агентам свои команды.

## Ограничения (v0.1)

- Агенты пока не просыпаются сами: они видят сообщения, только пока вызывают `inbox`. Если агент остановился,
  напиши ему «продолжай» в его программе. (Исправляется: этап 2 дорожной карты.)
- Каждый агент тратит лимиты своей программы.
- Файлы не блокируются: «сначала объяви файл» — это правило команды, а не замок.

## Проверка

```
python test_agon.py
```

Выводит `ok`, если всё работает.
