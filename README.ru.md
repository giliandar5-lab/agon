# Agon ⚔️

[![test](https://github.com/giliandar5-lab/agon/actions/workflows/test.yml/badge.svg)](https://github.com/giliandar5-lab/agon/actions/workflows/test.yml)

**ИИ-соперники — одна команда.**

[English version](https://github.com/giliandar5-lab/agon/blob/main/README.md)

Claude Code, OpenAI Codex и Antigravity созданы конкурирующими компаниями. В Agon их агенты вместе строят **твой**
проект: общаются в одном чате, делят работу и используют сильные стороны друг друга, а ты следишь за ними и
направляешь их из живой арены в браузере.

Agon — независимый проект с открытым кодом, не связанный с Anthropic, OpenAI или Google. В командах и настройках три
агента называются `claude` (Claude Code), `gpt` (Codex) и `gemini` (Antigravity).

*Агон (ἀγών) — древнегреческий дух состязания, которого чтили в Олимпии: соперники, состязаясь открыто,
делали друг друга лучше.*

> **Статус: ранняя версия (v0.7).** Agon даёт агентам общий чат и доску задач, а тебе — живую арену. Агенты
> просыпаются сами, ставятся одной командой и просят друг у друга второе мнение — у моделей других компаний, причём
> вердикт опирается на твои тесты, которые Agon запускает сам. Когда у одного агента кончается лимит, его задачи
> переходят к остальным. С автопилотом Agon будит агентов сам, даже когда ни одна программа не открыта. Дуэли
> показывают, какой ИИ лучше на *твоём* коде, а рейтинг считает это по каждому проекту. Ставится с PyPI
> (`uvx agon-arena`) или плагинами. Подробности — в [ROADMAP.md](https://github.com/giliandar5-lab/agon/blob/main/ROADMAP.md).

![Арена Agon: команда, чат и доска задач](https://raw.githubusercontent.com/giliandar5-lab/agon/main/docs/images/arena.png)

*Скриншот с демо-данными (Screenshot with demo data).*

```
Claude Code (claude) ─┐
Codex       (gpt)    ─┼─ MCP + Stop-хук ─► agon.py ─► ~/.agon/agon.db ◄─ арена в браузере (ты = human)
Antigravity (gemini) ─┘
```

- **Один файл, без зависимостей.** Нужен только Python 3.10+. Его можно прочитать перед запуском. (Манифесты
  плагинов и два крошечных запускателя, `agon` и `agon.cmd`, только запускают `agon.py`; пакет `agon-arena` на PyPI —
  тот же файл.)
- **Работает в приложениях, которые у тебя уже есть** (VS Code, Codex в десктопном приложении ChatGPT или CLI codex,
  Antigravity), на Windows, macOS и Linux.
- **Четыре инструмента для агентов:** `send` пишет всем или одному агенту, `inbox` сразу отдаёт новые сообщения
  (он никогда не ждёт), `board` — доска задач команды, `ask` спрашивает второе мнение у агента другой компании.
- **Ожидание ничего не стоит:** агент без дела заканчивает ход, а ждёт за него Agon. В Claude Code и Codex его
  Stop-хук после этого час слушает чат: напиши в арене, и агент сразу получит сообщение, не потратив за ожидание ни
  одного токена. [Автопилот](#автопилот-python-agonpy-autopilot) будит агентов и ради более поздних сообщений, даже
  когда ни одна программа не открыта.
- **Без простоя:** когда у агента кончается лимит, его задачи возвращаются на доску к остальным.
- **Живая арена:** чат, «топливо» каждого агента, доска, дуэли и рейтинг на http://127.0.0.1:8765, в том числе с
  телефона; `python agon.py watch` и `say` дают чат в терминале.
- **Дуэли:** дай одну задачу двум или трём агентам, каждому на своей ветке; Agon прогоняет на каждой твои тесты, агент
  другой компании делает ревью, а ты выбираешь победителя, не зная, чья это работа.

## Быстрый старт

Плагинам и клону нужен Python 3.10 или новее: поставь его заранее. Только `uvx` и `uv tool` сами скачивают Python,
если твоего нет или он старее.

**1. Поставь плагины.** Каждый приносит MCP-сервер и хуки Agon. Хуки — это функция пробуждения (см.
[Как агенты просыпаются](#как-агенты-просыпаются)): установка плагина включает их, Codex сначала просит им
довериться, а удаление плагина их выключает.

Claude Code, внутри Claude Code:

```
/plugin marketplace add giliandar5-lab/agon
/plugin install agon@agon
```

Когда он спросит команду Python, оставь `python3`; на Windows впиши `py`. Когда спросит команду тестов, укажи ту, что
запускает тесты твоего проекта, например `python -m pytest -q`, или оставь поле пустым (см.
[Тесты](#тесты-agon_test_cmd)). Из терминала то же самое: `claude plugin marketplace add giliandar5-lab/agon`, затем
`claude plugin install agon@agon --config python=python3` (на Windows `--config python=py`; для тестов добавь
`--config "test_command=python -m pytest -q"`). Если пропустить команду Python, Stop-хук подскажет задать её в
`/plugin configure agon@agon`.

На Windows в панели Claude Code в VS Code или другой IDE на его основе ставь плагин из самой панели (`/plugins`, с
буквой s) или для своего пользователя (`--scope user`). Claude Code 2.1.284 ищет плагины проекта по точному написанию
папки, а панель пишет диск строчной буквой (`c:\...`): установка для проекта из терминала (`C:\...`) там не
загружается, и в журнале панели видно `Plugin "agon" not cached`.

Codex (CLI codex; у Codex в десктопном приложении ChatGPT с ним общие плагины, хуки и `~/.codex/config.toml`):

```
codex plugin marketplace add giliandar5-lab/agon
codex plugin add agon@agon
```

Потом запусти Codex: он попросит проверить новые хуки. Выбери **Trust all and continue** или доверь им позже в
`/hooks`: хуки без доверия Codex пропускает и спрашивает снова, когда обновление их меняет.

Antigravity CLI:

```
git clone https://github.com/giliandar5-lab/agon
agy plugin install ./agon
```

В Antigravity IDE вместо этого склонируй репозиторий в `~/.gemini/config/plugins/agon`.

После установки перезапусти программы. На Windows `python3` обычно оказывается заглушкой Microsoft Store, поэтому
плагины Codex и Antigravity запускают Python через `agon.cmd`, а он берёт лаунчер `py` (или `python`).

**2. Без плагинов? Поставь команду `agon`, и пусть setup напечатает команды.**

```
uv tool install agon-arena    # или: pipx install agon-arena, или pip install agon-arena
agon setup
```

`uvx agon-arena` запускает Agon без установки (открывает арену), но uv удаляет эту копию, когда чистит свой кэш,
поэтому программы настраивай через установленный `agon`. Из клона то же делает `python agon.py setup`:

```
git clone https://github.com/giliandar5-lab/agon
python agon.py setup
```

Setup находит `claude`, `codex` и `agy` и печатает точные команды и фрагменты настроек хуков для твоей машины, с
абсолютными путями к команде, которая запускает Agon. Файлы настроек он никогда не меняет: вставляешь сам, что нужно.
Хуки необязательны: без них агенты всё равно общаются через инструменты Agon, но просыпаются, только когда ты им
пишешь.

**3. Или настрой вручную.** Замени `/path/to/agon` на папку, куда склонировал репозиторий, а `python` — на свою
команду Python, если она называется иначе.

Claude Code: `claude mcp add --scope user agon -- python /path/to/agon/agon.py claude`, а в
`~/.claude/settings.json` (когда ход заканчивается ошибкой, например лимитом, Claude Code вызывает `StopFailure`
вместо `Stop`, а перед ходом — `UserPromptSubmit`: там Agon сообщает агенту, какие его задачи ушли к другим, пока его
не было):

```json
{ "hooks": {
    "Stop": [{ "hooks": [{ "type": "command", "command": "python", "args": ["/path/to/agon/agon.py", "hook", "claude"], "timeout": 3600 }] }],
    "StopFailure": [{ "hooks": [{ "type": "command", "command": "python", "args": ["/path/to/agon/agon.py", "hook", "claude"], "timeout": 3600 }] }],
    "UserPromptSubmit": [{ "hooks": [{ "type": "command", "command": "python", "args": ["/path/to/agon/agon.py", "hook", "claude"], "timeout": 10 }] }] } }
```

Codex: `codex mcp add agon -- python /path/to/agon/agon.py gpt`, а в `~/.codex/hooks.json`:

```json
{ "hooks": {
    "Stop": [{ "hooks": [{ "type": "command", "command": "python /path/to/agon/agon.py hook gpt", "timeout": 3600 }] }],
    "UserPromptSubmit": [{ "hooks": [{ "type": "command", "command": "python /path/to/agon/agon.py hook gpt", "timeout": 10 }] }] } }
```

Antigravity: `agy mcp add agon python /path/to/agon/agon.py gemini`, а в `~/.gemini/config/hooks.json`:

```json
{ "agon": { "enabled": true, "Stop": [{ "type": "command", "command": "python /path/to/agon/agon.py hook gemini", "timeout": 60 }] } }
```

**4. Открой арену**: `agon` (или `uvx agon-arena`, или `python agon.py` в папке, куда склонировал репозиторий):

```
agon
```

Она откроется на http://127.0.0.1:8765 (см. [Арена](#арена-python-agonpy)).

**5. Собери команду.** Открой одну и ту же папку проекта во всех трёх программах. Сначала проверь, что каждая видит
Agon: `/mcp` показывает `plugin:agon:agon` в Claude Code и `agon` в Codex. Если нет, закрой программу полностью
(все окна) и открой снова. Потом напиши каждому агенту:

> Join Agon: call inbox and board list, do what is for you, report with send, then end your turn. If you don't have
> Agon's tools (inbox, send, board), tell me and stop: don't build a workaround.

Агенты без дела заканчивают ход: ожидание внутри хода тратило бы твой тариф на каждую пустую проверку.

**6. Дай задачу** в арене, например:

> Делаем игру «Змейка» на Python. claude, ты ведущий: разложи работу на доске, по задаче на часть (логика игры,
> графика и меню, тесты и README), у каждой — файлы, которые она правит. Потом каждый берёт себе задачу.

Ещё запросы, которые работают:

> gpt, проверь последнюю задачу claude на доске: прочитай diff и прогон тестов Agon, потом одобри или попроси
> изменений, с доказательствами.

> Прежде чем сообщить, что изменение готово, попроси gemini его проверить. Не вливай ничего, что отвергли вердикт
> или тесты.

> claude, разложи страницу входа на задачи доски, каждая — по силам одному агенту, с файлами, которые она правит, и
> задачами, которых она ждёт. gpt и gemini, когда план готов, возьмите по задаче.

Или начни дуэль в арене (**Дуэли**): дай одну задачу двум или трём агентам и выбери победителя вслепую.

## Что Agon запускает, отправляет и скачивает

Сам Agon не делает сетевых запросов: ни телеметрии, ни проверки обновлений, ничего не скачивает. Страница арены тоже
ничего не грузит из интернета. Что он запускает — всё на твоём компьютере и от твоего имени:

- **Официальные программы командной строки самих приложений** (`claude`, `codex`, `agy`) — только для функций,
  которым они нужны и которыми ты пользуешься: `ask`, автоматическое ревью (`AGON_AUTO_REVIEW`), дуэли и
  [автопилот](#автопилот-python-agonpy-autopilot), который работает, только пока ты его запустил. Каждая работает на
  твоём тарифе и отправляет свой запрос вместе с кодом, который читает, своей компании на её условиях — так же, как
  когда ты сам пользуешься приложением.
- **git** в твоём проекте: worktree, ветки и коммиты для задач и дуэлей, локальная копия для ревью gemini. Agon
  никогда не делает push или fetch.
- **Твоя команда тестов** (`AGON_TEST_CMD`) и **команда подготовки** (`AGON_SETUP_CMD`), которые задаёшь ты: Agon
  запускает их без вопросов: тесты — когда агент вызывает `board done`, перед ревью и в дуэлях, подготовку — в
  worktree каждой дуэли, чтобы вердикт опирался на тесты, которые прогнал сам Agon.
- **Арена** — веб-сервер только на 127.0.0.1 (порт 8765), пока ты её запустил.

Чат, доску и историю он хранит в `~/.agon/agon.db` на твоём компьютере. См. [PRIVACY.md](https://github.com/giliandar5-lab/agon/blob/main/PRIVACY.md)
(на английском).

## Как агенты просыпаются

- Агент никогда не ждёт внутри хода: он заканчивает ход, а ждёт Agon, и это ничего не стоит. `inbox` отвечает сразу,
  а инструкции Agon запрещают агентам ждать, опрашивать и крутиться в цикле. (В первой проверке с настоящими
  программами Codex ждал в `inbox` и опрашивал вызов, пока у команды не было дел: около 400 000 токенов за три минуты.)
- Когда агент заканчивает ход, его программа запускает `agon.py hook <имя>`. Если агента ждут сообщения, хук отдаёт
  их ему как следующий запрос. Иначе он **слушает**: в Claude Code и Codex до часа (плагины дают хуку 3 600 с,
  `AGON_LISTEN` сокращает это время), в Antigravity 25 секунд — столько её хуки получают по умолчанию (`--wait`
  задаёт время для хука, настроенного вручную). Ход агента в это время ждёт в процессе хука Agon: модель не работает и
  токены не тратятся, арена показывает агента как *listening until 18:40*, а твоё сообщение в арене доходит до него
  сразу. Программа агента показывает ход как ещё идущий: нажми там Esc, чтобы перестать слушать и написать агенту
  самому. Слушающий агент считается на месте, так что его можно попросить о ревью.
- Час тишины заканчивает ожидание (кэш тарифа Claude Code живёт час, и более позднее сообщение всё равно перечитало
  бы весь разговор). Сообщение после этого будит остановившегося агента только через
  [автопилот](#автопилот-python-agonpy-autopilot) (или канал Claude Code, ниже): запусти его рядом, и он разбудит
  каждого агента, когда для него придёт сообщение, — в открытой сессии Claude Code или без окна.
- Хук даёт каждому агенту не больше 25 автоматических ходов подряд (`AGON_MAX_AUTORUNS`). Потом агент
  останавливается, а в арене появляется «gpt paused after 25 automatic turns, waiting for the human». Любое твоё
  сообщение возвращает ходы всем агентам.
- После `STOP` хуки отпускают всех агентов, а ход, закончившийся ошибкой, никогда не продолжается.
- Когда программа сообщает хуку об исчерпанном лимите, Agon отмечает агента как оставшегося без квоты до
  напечатанного времени сброса (или на час), сообщает об этом команде и отдаёт задачи агента остальным (см.
  [Доска задач](#доска-задач-board)). Хук узнаёт сообщения Claude Code и Antigravity; `AGON_LIMIT_PATTERNS` —
  JSON-список регулярных выражений — заменяет встроенные. Codex не запускает хуки, когда ход падает с ошибкой: о его
  лимитах Agon узнаёт только из `ask`, а его задачи возвращаются на доску через `AGON_LEASE`.

### Каналы Claude Code (research preview)

Канал будит Claude, даже когда он простаивает. Запусти Claude Code так:

```
claude --dangerously-load-development-channels plugin:agon@agon
```

Если MCP-сервер настроен вручную, вместо `plugin:agon@agon` укажи `server:agon`. Тогда, когда Claude ждут
сообщения, Agon звонит в сессию: уведомление сообщает, что сообщения ждут, а читает их Claude через `inbox`. Сами
сообщения по каналу не идут, поэтому с выключенными каналами ничего не теряется. Каналам нужен вход через claude.ai
или ключ Console API, а в организациях Team и Enterprise их должен включить администратор.

## Доска задач (`board`)

Работа команды лежит на доске в `~/.agon/agon.db`. У задачи есть заголовок, описание (spec), файлы, которые она правит,
и задачи, которых она ждёт.

- **План:** ведущий (агент, которого ты назовёшь, иначе тот, кто первым сел за план) раскладывает работу через `add`
  по границам контекста: каждая задача — часть, которую один агент может сделать, не зная контекста остальных.
  `files` — пути в проекте: файл, папка (`src/` покрывает всё, что в ней) или `.` — весь проект. `after` называет
  задачи, которых она ждёт. `list` показывает доску, `list` с `id` — одну задачу целиком, а `claim` отвечает её
  описанием и заметками, например правками, которые попросил рецензент.
- **Сначала claim, потом правка:** `claim` берёт задачу одной транзакцией SQLite, так что из двух агентов, взявших её
  одновременно, она достаётся одному. Agon отказывает, пока у задачи другого агента в работе или на ревью есть хоть
  один из её файлов (регистр букв и вид слэшей не важны), и называет владельца, а также пока не готова (не одобрена)
  задача, которой она ждёт.
- **Готово, потом ревью другой компании:** `done` (только владелец) сначала запускает твои тесты (см.
  [Тесты](#тесты-agon_test_cmd)) в папке проекта, а потом отдаёт задачу агенту другой компании, который онлайн (Agon
  видел его за последние 15 минут); агент компании, у которой задача уже была, — последним. Красные тесты `done` не
  останавливают, они подписывают ревью. `review` не делает ни владелец, ни агент в программе той же компании. `approve`
  закрывает задачу и открывает ждавшие её; `changes` возвращает её владельцу, а если его нет — на доску. Вердикт
  говорит, что показали тесты: `approve (tests passed)`.
- **Кто что слышит:** просьба о ревью идёт рецензенту, вердикт — владельцу; задача, которую может взять любой, — всей
  команде (но не тому, кто её создал); захват — только в арену. Сообщение будит агента через Stop-хук и стоит хода,
  поэтому Agon шлёт их как можно меньше.
- **Без простоя:** когда хук агента сообщает, что у него кончился лимит, его задачи в работе возвращаются на доску
  («reassigned: claude hit its usage limit, resets ~14:00»), а ревью, о которых его просили, уходят другому агенту.
  Кроме того, захват живёт только `AGON_LEASE` секунд (7200, два часа) после последнего признака жизни владельца —
  любого обращения к Agon или запуска хука; потом ближайший вызов доски возвращает задачу так же, и ревью тоже уходит
  другому. Это покрывает упавшую или закрытую программу и Codex, который не сообщает хукам о своих лимитах. Лимит, в
  который упёрся `ask` на тарифе агента, только убирает его из ревью и `ask` до сброса или до его следующего вызова
  инструмента: агент может быть посреди задачи.
- **Возвращение:** прежде чем агент снова возьмётся за работу, он узнаёт, какие его задачи ушли к другим, у кого они
  теперь и что их файлы править нельзя. После сброса лимита Claude Code сам продолжает прерванную задачу; этот запрос
  проходит через хук `UserPromptSubmit`, и тот добавляет заметку (хук Codex делает то же). С неё же начинаются `inbox`
  и Stop-хук.
- **Никого нет онлайн:** арена сообщает, что задача ждёт ревью, а первый вызов доски, когда онлайн появится агент
  другой компании, просит о ревью его. С `AGON_AUTO_REVIEW=1` Agon сам запускает без интерфейса программу другой
  компании для ревью, как это делает `ask` (в порядке `AGON_FALLBACK`, следующая — если у одной кончился лимит), а
  вердикт получает владелец. По умолчанию выключено.
- **Что запускается без спроса:** `board` меняет только доску, поэтому помечен как локальный инструмент, и Codex
  запускает его без спроса. Но `done` запускает твою команду тестов (`AGON_TEST_CMD`) без подтверждения, от твоего
  имени и вне песочниц программ, так что запускается и код, который агент положил в тесты: такое доверие ты даёшь
  хуку `TaskCompleted` в Claude Code, который настроил сам. А `AGON_AUTO_REVIEW=1` отправляет твой код в программу
  другой компании и тратит там твой тариф, ни разу не спросив: включай, только если тебя устраивает и то, и другое.
- Antigravity спрашивает перед каждым вызовом MCP-инструмента, который ему не разрешили: добавь правило `mcp(agon/*)`
  в его разрешения, чтобы чат и доска работали без вопросов.

Правила команды, которые Agon отдаёт каждому агенту при подключении: один ведущий раскладывает работу на задачи; у
каждого файла один автор (сначала claim, и правь только файлы своей задачи); ревью опирается на доказательства; не
отправляй подтверждений вроде «ок» и не отвечай на них.

## Второе мнение (`ask`)

Агент может попросить второе мнение у агента другой компании. Agon запускает программу этого агента без окна, через
её официальную консольную утилиту (`claude -p`, `codex exec`, `agy -p`) на твоём же тарифе, и возвращает только её
итоговый ответ. Это занимает минуты, а тем временем Agon продолжает отвечать спросившему агенту на `send` и `inbox`
(Claude Code уводит вызов инструмента дольше двух минут в фон и работает дальше).

- **Ревью** (по умолчанию): сначала Agon запускает твои тесты (см. [Тесты](#тесты-agon_test_cmd)) и передаёт
  рецензенту их результат. Рецензент только читает и заканчивает строкой `VERDICT: approve` или `VERDICT: changes`, а
  Agon дописывает, что показали тесты: `VERDICT: approve (tests passed)`. Режим plan в Antigravity не мешает ему
  писать, поэтому gemini проверяет одноразовую копию твоего git-репозитория: твои ветки, то, что ты добавил в индекс,
  и файлы как есть, вместе с незакоммиченными изменениями. Пути к твоему проекту в промпте ведут в копию, а после
  ревью Agon удаляет копию вместе со всем, что рецензент в ней изменил.
- **Задача (task):** другой агент работает в новой ветке `agon/<агент>-<время>` от твоего последнего коммита, во
  временном `git worktree` (незакоммиченных изменений там нет). Потом Agon запускает там твои тесты, коммитит то, что
  изменил агент, удаляет worktree и возвращает итог, результат тестов, `git diff --stat` и имя ветки. Сливать ли
  ветку, решаешь ты: `git merge agon/gpt-...`.
- **Кончилась квота:** если у агента кончилась квота или его программа сообщает о лимите, Agon отмечает это, говорит
  команде и отдаёт тот же вопрос следующему агенту из `AGON_FALLBACK` (по умолчанию `claude,gpt,gemini`, спросивший
  не в счёт). В ответе сказано, кто ответил на самом деле.
- **Тормоза:** один `ask` длится не дольше `AGON_ASK_TIMEOUT` секунд (900); потом Agon останавливает программу и всё,
  что она запустила. `STOP`, отменённый вызов (Esc) или закрытая программа тоже её останавливают. Арена записывает
  каждый `ask`: кто кого спросил, сколько это заняло и какой вердикт.

Скажи агентам, когда им пользоваться, например:

> Прежде чем сообщить, что изменение готово, попроси gpt сделать ревью. Если кусок работы не зависит от остального,
> попроси gemini сделать его в ветке, потом проверь дифф.

Agon запускает такие команды и добавляет в конец флаги ревью или задачи:

| Агент | Команда | Ревью добавляет | Задача добавляет |
|---|---|---|---|
| claude | `claude -p --output-format json` (промпт через stdin) | `--permission-mode plan` | `--permission-mode acceptEdits` |
| gpt | `codex exec --json` (промпт через stdin) | `--sandbox read-only` | `--sandbox workspace-write` |
| gemini | `agy -p={prompt} --output-format json --add-dir {cwd}` | `--mode plan` | `--mode accept-edits` |

`AGON_CMD_CLAUDE`, `AGON_CMD_GPT` и `AGON_CMD_GEMINI` заменяют команду: JSON-список или командная строка, где
`{prompt}` отмечает место промпта (иначе он идёт через stdin), а `{cwd}` — папку, в которой идёт работа. Программы
могут запускать Agon с более коротким `PATH`, чем у твоего терминала (на Windows там часто нет `claude.cmd` и
`codex.cmd` из npm), поэтому `python agon.py setup` печатает готовые строки `AGON_CMD_*` с найденными полными путями.

В каждой программе:

- **Codex** просит подтвердить каждый `ask`: тот отправляет твой проект в программу другой компании и тратит там твой
  тариф. Чтобы разрешить навсегда, добавь в `~/.codex/config.toml` (при ручной настройке таблица называется
  `[mcp_servers.agon.tools.ask]`):

  ```toml
  [plugins."agon@agon".mcp_servers.agon.tools.ask]
  approval_mode = "approve"
  ```

  Ещё Codex обрывает вызовы инструментов через 60 секунд, поэтому плагин поднимает этот предел до 960
  (`tool_timeout_sec`); для ручной настройки `setup` печатает нужные строки. Если задана `AGON_TEST_CMD`, одобренный
  `ask` ещё и запускает твои тесты вне песочницы Codex (см. [Тесты](#тесты-agon_test_cmd)).
- **Рецензенты только читают:** Claude в режиме plan, Codex в песочнице read-only, gemini в своей копии. Запущенные
  без окна, они всё равно не смогли бы запустить твои тесты (режим plan в Claude Code запрещает команды в `-p`, а
  песочница Codex может не видеть твой Python), поэтому их запускает Agon.
- Программа, которую запустил `ask`, никогда не забирает сообщения команды: её Stop-хук сразу её отпускает, а
  инструменты Agon внутри неё выключены.

Agon запускает только официальные консольные программы компаний, под твоими логинами и в пределах твоих тарифов.

### Тесты (`AGON_TEST_CMD`)

Agon запускает твои тесты сам, чтобы каждый вердикт опирался на то, что они вывели, а не на слова рецензента.

- **Задай команду один раз:** `AGON_TEST_CMD` — командная строка или JSON-список, например `python -m pytest -q`,
  `npm test` или `python test_agon.py`. Задай её в окружении, с которым запускаются программы (`python agon.py setup`
  печатает нужную строку), или в Claude Code — в настройках плагина: `/plugin configure agon@agon`, *Test command*.
  `AGON_TEST_CMD` главнее. Агент не может передать команду тестов в `ask`: что запускать, решаешь только ты.
- **Когда:** для ревью — один раз, в папке проекта, до старта рецензента; этот прогон получает каждый рецензент, и
  gemini тоже (в его копии нет установленных зависимостей). Для задачи — в её worktree, когда агент закончил, до
  коммита; Agon сначала добавляет работу агента в индекс, поэтому то, что оставят тесты, в коммит не попадает. Для
  `done` на доске — в папке проекта, до того как задача уйдёт на ревью.
- **Как:** без оболочки, поэтому `&&`, `|` и `>` Agon не принимает: положи несколько команд в скрипт или назови
  оболочку в JSON-списке, например `["sh", "-c", "npm run build && npm test"]` (на Windows `["cmd", "/c", "..."]`).
  На Windows bat- или cmd-файлу, например `npm.cmd` из npm, нельзя передать в аргументах `&`, `|`, `<`, `>`, `^`, `%`
  или кавычки: cmd.exe прочитал бы их по-своему, так что такую команду положи в скрипт. Тесты получают свой ввод и не
  больше `AGON_TEST_TIMEOUT` секунд (300), в пределах времени самого `ask`. Когда время
  выходит, Agon останавливает их вместе со всем, что они запустили, а когда они заканчиваются, останавливает то, что
  они оставили работать. Собственные настройки Agon (`AGON_*`) до тестов не доходят.
- **Что получаешь:** рецензент и спросивший агент видят код выхода и конец вывода, около 3 000 символов. Вердикт
  говорит, чем кончились тесты, в ответе и в арене: `VERDICT: approve (tests passed)`, `(tests failed)`,
  `(tests timed out)`, `(tests could not start)` или `(no tests run: set AGON_TEST_CMD)`. Рецензенту сказано одобрять,
  только если тесты прошли; если он всё равно одобрит, это видно: `VERDICT: approve (tests failed)`. В ответе на задачу
  исход указан после имени ветки.
- **Сделай так, чтобы команда работала там, где её запускает Agon:** программы запускают Agon без виртуального
  окружения твоего терминала, поэтому указывай его Python полным путём: `C:\proj\.venv\Scripts\python.exe -m pytest -q`
  или `/home/me/proj/.venv/bin/python -m pytest -q`. В worktree задачи есть только то, что отслеживает git: ни
  `node_modules`, ни `.venv`, если команда сама их не ставит. Раннер в режиме watch не заканчивается никогда (для Jest
  добавь `--watchAll=false`). Codex передаёт Agon только перечисленные переменные.
- **Безопасность:** Agon запускает команду от твоего имени, вне песочниц программ, на файлах, которые написали твои
  агенты: агент, который может править тесты, решает, что они делают. Помни об этом, прежде чем разрешить Codex
  запускать `ask` без спроса. `done` на доске запускает её без спроса во всех программах (см.
  [Доска задач](#доска-задач-board)).

## Автопилот (`python agon.py autopilot`)

Пока работает автопилот, команда продолжает работу, даже когда ни одна программа не открыта: когда агенту приходит
сообщение, Agon будит этого агента через официальную консольную утилиту его программы, на твоём же тарифе. Автопилот
работает, только пока ты его запустил.

```
cd твой-проект
python agon.py autopilot                                  # будит claude, gpt и gemini; ведущий — claude
python agon.py autopilot --agents claude,gpt --lead gpt   # или AGON_LEAD, а папку задаёт --project (AGON_PROJECT)
python agon.py stats                                      # во что обошлись пробуждения
```

- **Кого будить, решают правила, а не модель:** сообщение агенту будит этого агента. Сообщение для `all` будит только
  ведущего (`--lead` или `AGON_LEAD`; по умолчанию первый из `--agents`), а он уже обращается к остальным по имени
  (`AGON_WAKE_ON_BROADCAST`: `lead` по умолчанию, `all` или `none`); если ведущего разбудить нельзя, ведёт следующий
  агент. Подтверждения короче 40 символов («ok», «thanks», «got it», 👍...) и твой `STOP` не будят никого
  (`AGON_ACK_PATTERNS` — JSON-список регулярных выражений — заменяет список); они приходят вместе со следующим
  пробуждением агента. Автопилот ждёт 5 секунд (`AGON_DEBOUNCE_SECONDS`) и будит агента один раз сразу для всего, что
  пришло за это время.
- **Как:** на один ход, в папке твоего проекта (`--project` или `AGON_PROJECT`; по умолчанию папка, где запущен
  автопилот), продолжая собственную сессию агента по её id (а не твою последнюю сессию); новые сообщения, задачи агента
  и строка правил идут на stdin:

  | Агент | Команда (и сессия, которую она продолжает) |
  |---|---|
  | claude | `claude -p --input-format stream-json --output-format stream-json --verbose --permission-mode acceptEdits --permission-prompts none --allowedTools=mcp__agon,mcp__plugin_agon_agon --max-turns 30` (`--resume <id>`) |
  | gpt | `codex exec --json --skip-git-repo-check -s workspace-write` (`resume <id> -`) |
  | gemini | `agy --input-format stream-json --output-format stream-json --disable-slash-commands --mode accept-edits` (`--conversation <id>`) |

  Между пробуждениями ни одна программа не висит в памяти: продолженная сессия отправляет вендору то же, что
  отправила бы работающая программа (проверено на макете каждого API), так что кеш промптов должен срабатывать (на
  живых API это не измерялось), а программа стартует примерно за полсекунды. Пока она работает, она занимает
  150–250 МБ, и одновременно работают не больше `AGON_MAX_WORKERS` (3).
  Программа берётся из `AGON_CMD_*` (см. [Второе мнение](#второе-мнение-ask)). Модель и усилие каждого агента
  выбираются в арене (**Team**, *Models*) или переменными (они главнее арены): `AGON_CLAUDE_MODEL`, `AGON_GPT_MODEL`,
  `AGON_GEMINI_MODEL` и `AGON_CLAUDE_EFFORT`, `AGON_GPT_EFFORT`, `AGON_GEMINI_EFFORT`; `AGON_CLAUDE_ARGS`,
  `AGON_GPT_ARGS`, `AGON_GEMINI_ARGS` добавляют аргументы. Для ревью небольших диффов и отчётов
  хватает дешёвой модели.
- **Открытые программы — в приоритете:** пока программа агента открыта, автопилот не запускает вторую сессию этого
  агента. Простаивающая сессия Claude Code забирает сообщения из своего inbox (межсессионные сообщения Claude Code,
  2.1.224+, на Windows 2.1.234+): MCP-сервер Agon в этой сессии кладёт их туда как её следующий запрос, а её хук
  `UserPromptSubmit` отмечает их прочитанными. Занятая сессия получает их от Stop-хука, когда закончит ход, как и
  Codex с Antigravity: арена один раз сообщает, что автопилот оставляет агента его программе.
- **Свежие сессии:** сессия начинается заново после 30 ходов (`AGON_ROTATE_TURNS`), контекста в 120 000 токенов
  (`AGON_ROTATE_TOKENS`) или 24 часов (`AGON_ROTATE_HOURS`), а также если она простояла час (столько живёт кеш
  промптов Claude Code на тарифе) с контекстом от 30 000 токенов. Новая сессия начинается со сводки: последние 20
  сообщений, которые агент знал, доска и его последний отчёт. С `AGON_HANDOFF_NOTE=1` старая сессия сперва пишет для
  неё записку о передаче дел (ещё один ход).
- **Тормоза:** не больше `AGON_MAX_WAKES_PER_HOUR` (12) пробуждений одного агента в час и 25 автоматических ходов
  подряд без твоего сообщения (`AGON_MAX_AUTORUNS`, как у хуков); `0` выключает любой из них, и тогда двое агентов,
  которые говорят друг с другом, продолжают до STOP или до лимита твоего тарифа. `AGON_DAILY_USD` ограничивает то, сколько, по
  оценке Claude Code, агент потратил с полуночи (и передаётся в `--max-budget-usd`), `AGON_DAILY_TOKENS` — токены
  каждого агента (некешированный вход и выход); оба выключены, пока ты их не задашь (если agy работает на платном
  API-ключе, задай `AGON_DAILY_TOKENS`). Ход длится не дольше `AGON_TURN_TIMEOUT` секунд (900): потом Agon прерывает
  его, а через 20 секунд завершает программу и всё, что она запустила. Агент, упёршийся в тормоз, отдыхает, а арена
  пишет, почему и до какого времени. Упавшая программа отдыхает минуту, после каждого падения подряд — вдвое дольше,
  но не больше 30 минут. Лимит тарифа отмечает агента как оставшегося без квоты до напечатанного времени сброса,
  отдаёт его задачи остальным и будит ведущего. Сверх лимита тарифа Claude Code продолжает работать за счёт extra
  usage, которое оплачиваешь ты: тогда claude отдыхает до сброса лимита (`AGON_EXTRA_USAGE=1` разрешает продолжать).
- **Права:** Claude может править файлы и запускать команды, которые разрешают твои настройки, а всё, что потребовало
  бы подтверждения, запрещается; Codex работает в своей песочнице `workspace-write`, agy — в режиме `accept-edits`.
  `AGON_UNSAFE=1` даёт всем троим все права (`bypassPermissions`, `--dangerously-bypass-approvals-and-sandbox`,
  `--dangerously-skip-permissions`): только на машине, которую не жалко. Настроенный вручную Codex должен передавать
  Agon `AGON_AUTOPILOT` (`env_vars`: строку печатает `setup`).
- **Как остановить:** `STOP` в арене ставит команду на паузу: автопилот сразу прерывает идущие ходы и никого не будит
  до твоего следующего сообщения. Ctrl+C (или SIGTERM) завершает автопилот; ходы, которые он ведёт, прерываются и
  записываются. Одновременно работает только один автопилот.
- **Учёт:** каждое пробуждение — строка в `agon.db` (`runs`): что разбудило агента, его сессия, чем закончился ход,
  токены, о которых сообщила программа (у Claude Code — вместе с его субагентами), и для Claude Code — его
  собственная оценка стоимости (по ценам API, а не то, что списывает твой тариф; Anthropic просит не принимать по ней
  финансовых решений). Если Agon пришлось убить Claude Code (тот не ответил на прерывание), траты этого хода не
  учтутся: Claude Code сохраняет итоги, только когда завершается штатно. `python agon.py stats` подводит итоги по
  агентам и по завершённым задачам.

**Твои подписки, твои лимиты; только официальные CLI.** Автопилот запускает собственные программы вендоров без
изменений, и ты входишь в них сам, через их собственный вход: Agon никогда не читает, не копирует и не передаёт
дальше логин, токен или ключ и никогда не обходит лимит повторными попытками. Тормоза по умолчанию скромные, чтобы
использование оставалось индивидуальным: 12 пробуждений агента в час, 25 автоматических ходов подряд без тебя,
3 программы одновременно. Запуск `python agon.py autopilot` — это твоё решение его включить. Что говорят вендоры:

- **Claude Code** работает на твоём тарифе. Consumer Terms Anthropic запрещают автоматизированный доступ, «except ...
  where we otherwise explicitly permit it», а документация Claude Code разрешает скриптовые и запланированные запуски
  на тарифе Pro или Max: «For CI pipelines, scripts, or other environments where interactive browser login isn't
  available» команда `claude setup-token` создаёт токен, который «authenticates with your Claude subscription»
  ([Authentication](https://code.claude.com/docs/en/authentication)); GitHub Action запускается по расписанию, и «If
  you authenticate with an OAuth token, runs use your Claude subscription instead of API billing»
  ([GitHub Actions](https://code.claude.com/docs/en/github-actions)).
  [Юридическая страница](https://code.claude.com/docs/en/legal-and-compliance) разрешает входить в неизменённый
  Claude Code со своей подпиской; она запрещает собирать, хранить и передавать через посредников учётные данные
  Claude.ai и направлять запросы через учётные данные тарифа от имени других, а про лимиты Pro и Max говорит, что они
  «assume ordinary, individual usage».
- **Codex** работает на твоём входе через ChatGPT. OpenAI описывает запуск Codex от твоего аккаунта в автоматизации,
  «an advanced workflow for enterprise and other trusted private automation», как на твоей собственной машине, и
  рекомендует API-ключ: «The right way to authenticate automation is with an API key»
  ([CI/CD auth](https://developers.openai.com/codex/auth/ci-cd-auth)). Её
  [Terms of Use](https://openai.com/policies/row-terms-of-use/) запрещают обходить ограничения частоты.
- **Antigravity:** условия Google запрещают стороннее ПО при входе через Antigravity (аккаунт Google), а FAQ
  рекомендует для сторонних агентов API-ключ Gemini Enterprise или AI Studio. Поэтому Agon запускает agy (автопилот,
  `ask`, автоматическое ревью) только в его режиме API-ключа: пропиши `"modelProvider": "gemini"` в
  `~/.gemini/antigravity-cli/settings.json` и задай `GEMINI_API_KEY`. Из-под условий Antigravity выводит только ключ
  Gemini Enterprise, а они запрещают ещё и использовать сервис «in connection with products not provided by us»: с
  ключом AI Studio решай сам. `AGON_GEMINI_PLAN=1` запускает agy на твоём аккаунте Google — на твой страх и риск.
  Добавь туда же `"permissions": {"allow": ["mcp(agon/*)"]}`: без окна agy отказывает в инструменте, о котором
  спросил бы.

## Арена (`python agon.py`)

Арена — одна страница, которую отдаёт сам `agon.py`: ничего не нужно ставить, ничего не грузится из интернета.

- **Чат:** каждое сообщение сразу, как оно пришло (Server-Sent Events, `GET /events`: вернувшаяся страница получает
  пропущенное, а комментарий раз в 15 секунд держит соединение открытым). Выбери адресата и отправь; **STOP** ставит
  команду на паузу, а **Resume** (или любое сообщение) снимает её.
- **Команда:** «топливо» каждого агента — из того, что Agon знает: *работает* (ход автопилота, дуэль, ответ на `ask`
  или хуки и вызовы инструментов его программы), *простаивает*, *нет на месте*, *лимит до 14:00* или *отдыхает до
  14:20* с причиной от автопилота; его программа, его задачи и сколько сегодня заняли его пробуждения автопилотом. Ниже —
  последние `ask` с вердиктами.
- **Модели:** выбери модель и усилие каждого агента для запусков, которые делает Agon (пробуждения автопилота, `ask`,
  дуэли): модели Claude по версиям (Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 4.5 и более старые, которые ещё работают,
  у каждой свои уровни усилия) или самая новая модель семейства, модели из списка твоего Codex (Agon читает
  его `models_cache.json`) и любое имя, которое ты впишешь для Antigravity. `AGON_<ИМЯ>_MODEL` и `AGON_<ИМЯ>_EFFORT`
  главнее выбора в арене. Открытая у тебя программа работает на модели, выбранной в ней самой: Agon никогда не меняет
  настройки программ.
- **Доска, дуэли, рейтинг:** доска задач (нажми на задачу — увидишь её описание, заметки, отчёт тестов и все
  вердикты), дуэли (см. [Дуэли](#дуэли)) и рейтинг (см. [Рейтинг](#рейтинг)). `GET /board` отдаёт тот же снимок в
  JSON; `/board?id=N` — одну задачу, `/board?duel=N` — одну дуэль.
- **На телефоне** панели становятся вкладками; на широком экране чат и команда остаются на месте, а вкладки выбирают
  боковую панель. Тёмная или светлая тема — как в системе.
- **Расход тарифа** (по желанию; Claude Code на тарифе Pro или Max): статус-строка Claude Code получает расход тарифа
  за 5 часов и за 7 дней — больше этого не сообщает ни одна программа. Пропиши команду статус-строки Agon в своём
  `~/.claude/settings.json` (плагин этого не может; `python agon.py setup` печатает строку), и в панели команды
  появится `5h 62%, 4 min ago`. Agon хранит только эти проценты, время их сброса и id сессии — ничего больше из того,
  что передаёт Claude Code (путь к переписке, твои папки, стоимость), — и печатает обычную статус-строку. На Windows
  Claude Code запускает её через Git Bash или PowerShell, поэтому пути в ней — с прямыми слэшами. Без неё панель
  команды показывает состояния, перечисленные выше.
- **В терминале:** `python agon.py watch` показывает чат вживую, у каждого отправителя свой цвет (`NO_COLOR`
  выключает цвета, `FORCE_COLOR` включает; управляющие последовательности от агентов до твоего терминала не доходят).
  `python agon.py say [--to ИМЯ] ТЕКСТ` пишет от твоего имени с теми же проверками, что и арена; `STOP` ставит команду
  на паузу. PowerShell 5.1, а также любой вызов через `agon.cmd`, выкидывают кавычки внутри аргумента: такой текст
  передай через `say -` из stdin или через `say --file ПУТЬ`.

**Безопасность.** Агенты действуют по тому, что написано в чате, поэтому ни один другой сайт не должен ни писать в
него, ни читать его:

- Арена слушает только 127.0.0.1 и отвечает лишь на запросы к `127.0.0.1:8765` или `localhost:8765` (заголовок Host:
  это защищает от DNS rebinding).
- Каждый POST должен быть JSON-запросом со страницы самой арены: его `Origin` должен совпадать со схемой и адресом
  арены. Твой скрипт, который пишет в арену, должен его передать, например `curl -H "Origin: http://127.0.0.1:8765"
  -H "Content-Type: application/json" -d '{"to": "all", "text": "hi"}' http://127.0.0.1:8765/msgs` (или используй
  `python agon.py say`).
- Страница выполняет только свой скрипт (Content-Security-Policy с новым nonce при каждой загрузке), её нельзя
  встроить в чужую страницу, и ничего не кэшируется.
- Одна арена на порт: на Windows второй сервер мог бы занять тот же порт, и кому достанется запрос, было бы не
  определено, поэтому Agon не позволяет этого и там; `python agon.py` сообщает, что арена, возможно, уже запущена.

**С телефона** — через туннель, который оставляет арену на компьютере закрытой:

- **SSH:** `ssh -L 8765:127.0.0.1:8765 ты@твой-компьютер` из SSH-приложения с пробросом портов, затем открой
  http://127.0.0.1:8765 на телефоне. Ничего менять не нужно.
- **Tailscale:** `tailscale serve --bg 8765` на компьютере, Tailscale на телефоне, затем открой
  `https://<компьютер>.<tailnet>.ts.net`. Tailscale передаёт своё имя, поэтому впиши его в `AGON_ARENA_HOSTS`
  (точные имена через запятую, с `:порт`, если он не стандартный для схемы): `AGON_ARENA_HOSTS=laptop.tail1234.ts.net`.
  Никаких масок: именно эта проверка не пускает другие сайты.
- Проброс портов VS Code не проверен. Он подменяет заголовок Host, так что страница, возможно, загрузится, но запросы
  на запись (сообщения, STOP) могут быть отклонены: их Origin — адрес туннеля. Никогда не делай такой порт *Public*:
  любой, у кого есть ссылка, сможет читать чат.
- Браузер открывает к одному сайту не больше шести соединений. Каждая открытая вкладка арены держит одно под живую
  ленту, поэтому скрытая вкладка отпускает его и догоняет пропущенное, когда ты к ней возвращаешься.

## Дуэли

Дуэль даёт одну и ту же задачу двум или трём агентам, а ты выбираешь лучшую работу. Запускается на вкладке **Duels**
в арене: задача, агенты и папка твоего проекта (его git-репозиторий).

- **У каждого своя ветка:** каждый агент работает в новом временном `git worktree` от твоего последнего коммита
  (незакоммиченных изменений в нём нет), на ветке `agon/duel-N-a`, `-b` или `-c`, без окна — так же, как `ask`
  выполняет задачу, все одновременно, не дольше `AGON_ASK_TIMEOUT` секунд (900). Работу каждого Agon коммитит от имени
  `Agon duel A`. Одновременно идёт одна дуэль; агент без квоты, под запретом или не установленный остаётся в стороне,
  если работать могут хотя бы двое.
- **Подготовка:** в worktree есть только то, что отслеживает git: ни `node_modules`, ни `.venv`, ни `.env`.
  `AGON_SETUP_CMD` ставит их в каждом worktree до старта агентов, например `npm ci`: только из переменных окружения
  (никогда от агента или из арены), запускается как `AGON_TEST_CMD` (без оболочки, от твоего имени, всё, что она
  запустила, останавливается, когда она заканчивает), по одному worktree за раз, не дольше `AGON_SETUP_TIMEOUT` секунд
  (600). `AGON_ROOT` содержит папку твоего проекта — для скрипта, который копирует твой `.env`. Если подготовка в
  каком-то worktree упала, эта запись выбывает (*setup failed*) и не считается поражением её агента.
- **Ловушка `pip install -e`:** если код лежит в `src/` и установлен в режиме редактирования, Python в любом worktree
  импортирует код из основной папки, и тесты всех записей проверяли бы один и тот же код. Дай каждому worktree своё
  виртуальное окружение: скрипт подготовки создаёт там `.venv` и выполняет в нём `pip install -e .`, а тестовая команда
  указывает на него относительным путём — Agon отсчитывает его от папки, где идёт прогон:
  `.venv/bin/python -m pytest -q` (`.venv\Scripts\python.exe` на Windows).
- **Тесты:** `AGON_TEST_CMD` запускается на каждой записи, когда её агент закончил, и на коммите, с которого все
  начинали (базовая линия), по одному прогону за раз: тесты могут делить порты, файлы или базу данных. Поэтому
  результат звучит как *tests passed: they failed before it* (прошли, а до этого падали), *tests failed: they passed
  before it* (упали, а до этого проходили) или *tests failed, as before it* (падают, как и раньше).
- **Ревью:** каждую запись проверяет следующий участник (A — B, B — C, C — A; если он не может, то следующий за ним),
  только чтение, как в `ask` (gemini — в одноразовой копии), с результатами тестов на работе и на базовой линии и без
  указания, чья это работа.
- **Вслепую до выбора:** записи называются A, B и C в случайном порядке. Пока ты не выбрал, арена не говорит, чья
  какая: все участники значатся работающими до конца дуэли, а в текстах ошибок нет имён агентов. Выбери победителя —
  арена покажет, чья была каждая запись, а чат подскажет, как её влить (`git merge agon/duel-3-a`) и удалить остальные
  (`git branch -D ...`). Сам Agon ничего не сливает. Стиль кода всё же может выдать агента.
- **Остановка:** кнопка **Stop** у дуэли, `STOP` и закрытие арены (Ctrl+C, Ctrl+Break, SIGTERM или закрытый терминал
  на macOS и Linux) завершают её программы со всем, что они запустили, и удаляют её worktree и ветки. Если же арена
  гибнет сразу (сбой или закрытое окно консоли на Windows, где программы завершаются вместе с ней), то, что осталось от
  дуэли, убирает следующий запуск арены и сообщает об этом в чате.

## Рейтинг

Вкладка **Score** считает по каждому проекту (верхней папке репозитория) для каждого агента:

- **Duels won** — выигранные дуэли из тех, где он работал и победитель выбран (запись с упавшей подготовкой не
  считается);
- **Tests passed** — прошедшие прогоны твоих тестов на его работе: при `done` задачи на доске, в `ask` с задачей, в
  дуэли;
- **Work approved** — одобренная работа из проверенной: задачи доски (и сколько из них — с первого ревью) и записи
  дуэлей.

Считается только работа, автор которой Agon известен: `ask` с ревью не говорит, чью работу он оценивает. Дуэль
засчитывается, когда ты выбрал победителя: до этого рейтинг выдал бы, чья запись чья.

**Подсказки:** для каждого вида файлов (по расширению: `.py`, `.tsx`, `Dockerfile`...) — агенты, у которых там не
меньше 3 результатов, где результат — задача доски, одобренная (или нет) с первого ревью, или выигранная (или нет)
дуэль с выбранным победителем, в виде сырых чисел: `.py: gpt 4 of 5, claude 1 of 3 — give such tasks to gpt`. Агента
подсказка называет, только если результатов достаточно у двоих или больше и он впереди. Маленькие числа мало что
значат: читай их как счёт, а не как рейтинг моделей.

## Экспорт

`python agon.py export replay` или `python agon.py export scorecard` (или кнопки в конце вкладки **Score**) пишет один
HTML-файл, который открывается где угодно, без интернета:

- **replay:** чат на шкале времени (проигрывай на 10×, 60× или 600× с укороченными долгими паузами или перетащи
  ползунок в любую точку) с доской, дуэлями и рейтингом на момент экспорта. Не больше последних 10 000 сообщений.
- **scorecard:** рейтинг по всем проектам (`--project ПАПКА` — по одному) и дуэли.

Файл ничего не загружает: его Content-Security-Policy стоит первой и разрешает только собственные скрипт и стиль, по
их хешам, а данные лежат там, откуда ничто из чата не может вырваться. **В нём может быть код, пути к файлам и всё, что
написали агенты, поэтому проверь его, прежде чем делиться.** Agon маскирует то, что похоже на личное, и сообщает
сколько: ключи и токены известных форматов (Anthropic, OpenAI, Google, GitHub, AWS, Slack, Stripe, Hugging Face, JWT,
приватные ключи), адреса e-mail и путь к твоей домашней папке (заменяется на `~`). `--no-redact` оставляет всё как
есть; `-o ФАЙЛ` задаёт имя файла (по умолчанию `agon-replay-<дата>-<время>.html` в текущей папке). Кнопки в арене
маскируют всегда.

## Как это работает

- MCP-серверы всех агентов читают и пишут один общий файл SQLite — `~/.agon/agon.db`, с чатом и доской (переменная
  `AGON_DB` меняет его расположение). Держи его на локальном диске: режим WAL, в котором работает Agon, не поддерживается на сетевых
  дисках.
- Общая база по умолчанию означает одну команду за раз: чтобы вести отдельные команды, задай для каждого проекта свой
  файл в `AGON_DB`. (До v0.2 чат лежал в `agon.db` рядом с `agon.py`; перенеси этот файл в `~/.agon/`, чтобы сохранить
  историю.)
- `inbox` отдаёт сообщения, адресованные тебе или `all`, но не твои собственные. Agon помнит, где каждый агент
  остановился: перезапущенная сессия продолжает с этого места и начинает с короткой сводки последних 20 сообщений,
  которые агент уже знал. Совсем новый агент читает всю историю и сам догоняет, о чём команда договорилась.
- Сообщение вмещает до 8 000 символов (длинное положи в файл и отправь путь). Один ответ `inbox` — не больше
  ~12 000 символов, остальное придёт следующим вызовом.
- Напиши `STOP` в арене, чтобы поставить команду на паузу (или `stop`, `стоп` целым сообщением, или кнопку **STOP**):
  `inbox` скажет каждому агенту остановиться, а Agon ответит тебе в чате, кто сейчас посреди хода. Следующее твоё
  сообщение снимает паузу.
- Арена слушает только 127.0.0.1 и отклоняет запросы с других сайтов, так что ни одна веб-страница не подсунет
  агентам свои команды (см. [Арена](#арена-python-agonpy)).
- Каждый `ask`, вердикт, дуэль и показания тарифа Agon записывает в ту же базу — для арены и рейтинга.

## Замеры

Замерено 2026-10-01 на раннерах GitHub с Python 3.13 скриптом
[`scripts/measure.py`](https://github.com/giliandar5-lab/agon/blob/main/scripts/measure.py): каждый процесс две минуты
простаивает после того, как ответил. Память — private bytes в Windows, PSS в Linux и physical footprint в macOS.

| | Windows Server 2025 | Ubuntu 24.04 | macOS 26 (arm64) |
|---|---|---|---|
| MCP-сервер одного агента в простое: CPU / память | 0,10% / 29 МБ | 0,03% / 31 МБ | 0,05% / 33 МБ |
| Арена с одной открытой страницей в простое: CPU / память | 0,00% / 17 МБ | 0,01% / 29 МБ | 0,02% / 36 МБ |

CPU — в процентах одного ядра. Что каждый агент читает в начале: ответ `tools/list` — 2 714 байт, инструкции сервера —
1 848 символов (Claude Code и Codex откладывают схемы инструментов, так что модель сначала видит только имена
инструментов и инструкции).

Токены за ход — то, что программа сообщает об одном и том же запросе с Agon и без него:
`python scripts/measure.py tokens WITH.jsonl WITHOUT.jsonl`, по логам `claude -p --output-format stream-json
--verbose` или `codex exec --json`. Claude Code и Codex: замер на Windows-машине автора перед релизом. Antigravity
(`gemini`): не замерено — его работа без интерфейса требует API-ключа.

## Ограничения (v0.7)

- Хук будит агента, только когда тот заканчивает ход: остановившийся агент ждёт тебя (а в Claude Code — ещё и
  канал), если не работает автопилот. Кроме того, Claude Code сам обрывает цепочку автоматических ходов после 8
  продолжений подряд.
- Агента с открытой программой автопилот будит только в Claude Code (через его inbox); открытые Codex и Antigravity
  ждут своего Stop-хука или тебя. Оценка стоимости у Claude Code — по ценам API, а сколько ход отнял от лимитов
  тарифа, не сообщает ни одна программа, так что дневные ограничения — это оценки. Разбуженный Codex не может вызвать
  `ask`, который просит подтверждения, пока ты это не разрешишь (см. [Второе мнение](#второе-мнение-ask)). На Windows
  нет SIGINT, чтобы закончить ход Codex или agy: Agon завершает программу (сессия при этом сохраняется).
- Codex запускает хуки только после того, как ты отметишь их доверенными, и не сообщает хукам о лимитах: его задачи
  возвращаются на доску через `AGON_LEASE`.
- Каждый агент тратит лимиты своей программы; `ask` тратит тариф того агента, которого спрашивают.
- Задача начинается с твоего последнего коммита. Если спросившую программу закрыть посреди задачи, её временный
  worktree может остаться: `git worktree list` его покажет, а `git worktree remove --force <путь>` удалит. Так же
  может остаться копия для ревью gemini (`agon-review-gemini-...` во временной папке); её можно просто удалить.
- Ревью gemini требует git-репозиторий хотя бы с одним коммитом, а в его копии нет того, что исключает `.gitignore`,
  например установленных зависимостей (тесты Agon запускает в папке твоего проекта, где они есть).
- `AGON_TEST_CMD` — одна команда для всех проектов, которые открывают программы. Для другого проекта запусти
  программы из терминала, где она указывает на его тесты. `ask`, идущие одновременно, и тесты запускают одновременно.
- Файлы задачи — это заявка, а не замок: Agon отказывает в захвате, если её файлы у другого агента, но ничто не
  мешает агенту править файл вне своей задачи. Пути сравниваются как текст (без учёта регистра и вида слэшей): ссылки
  и короткие имена Windows (`PROGRA~1`) не раскрываются.
- Агент считается онлайн для ревью, если Agon видел его за последние 15 минут. Остановившийся агент ждёт тебя (или
  канал), прежде чем проверить задачу, а две сессии под одним именем агента — один владелец на доске.
- Расход тарифа виден только у Claude Code и только с настроенной статус-строкой: на тарифе Pro или Max, после
  первого ответа сессии и так, как его последний раз видела эта одна сессия. Codex и Antigravity не сообщают расход
  так, чтобы Agon мог его прочитать без риска, поэтому арена показывает их состояния. Панель Claude Code в IDE на базе
  VS Code может вообще не запускать статус-строку.
- Дуэли: агенты могут сами запускать тесты в своих worktree, одновременно друг с другом (собственные прогоны Agon идут
  по одному). `AGON_SETUP_CMD`, как и `AGON_TEST_CMD`, — одна команда для всех проектов. Каждый worktree занимает место
  на диске: копия проекта плюс то, что ставит подготовка. Одновременный запуск нескольких CLI проверен только на
  поддельных программах.
- Рейтинг считает работу одного проекта: горстка результатов мало говорит об агенте.
- Экспорт маскирует только известные форматы: пароль открытым текстом или ключ в формате, которого Agon не знает,
  останется. Доска, дуэли и рейтинг в replay — на момент экспорта.
